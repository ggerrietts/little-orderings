# Version Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detect when a newly-deployed build differs from the one currently loaded in a browser tab, and silently reload to the fresh build on the user's next click.

**Architecture:** A new unauthenticated, side-effect-free `GET /api/version` endpoint reports the running backend's git SHA (baked in at Docker build time). A frontend module polls that endpoint every 5 minutes (paused while the tab is hidden), compares the result against the SHA the currently-loaded bundle was built with, and — once a mismatch is seen — reloads the page on the next click that lands outside a text input.

**Tech Stack:** Rust/Axum backend (`sqlx`, no DB access needed for this feature), React 19/Vite frontend, Vitest for frontend tests, Docker multi-stage build, GitHub Actions (`build-and-push.yml`).

## Global Constraints

- `/api/version` must read and write nothing in the database — this is what keeps version polling decoupled from the push-notification debounce (`project_watches.notified_at`), per spec §5.
- Both sides must fall back to the literal string `"dev"` when their respective env var isn't set (`GIT_SHA` backend, `VITE_GIT_SHA` frontend), so local dev never sees a version mismatch and never triggers a spurious reload.
- Poll interval is exactly 5 minutes; polling stops while `document.hidden` is true and an immediate check runs when the tab becomes visible again.
- The reload trigger is `click` events only, and only when `event.target` is outside any `input`, `textarea`, or `[contenteditable]` element. No banner, no confirmation dialog — reload is silent.
- No new services, no DB schema changes, no changes to `docker-compose.prod.yml`, `deploy/admin.sh`, or `.env`/`.env.example` — `GIT_SHA` is a build-time-only value baked into the image, not a runtime secret.

- [ ] **Step 3: Write the minimal implementation for polling**

Create `frontend/src/versionWatch.ts`:

```typescript
import { version } from './api/client'
import { BUILD_VERSION } from './config'

const POLL_INTERVAL_MS = 5 * 60 * 1000

export function createVersionWatch() {
  let stale = false
  let intervalId: ReturnType<typeof setInterval> | null = null

  async function checkVersion() {
    try {
      const { version: serverVersion } = await version.get()
      if (serverVersion !== BUILD_VERSION) stale = true
    } catch {
      // network error — the next scheduled poll will just try again
    }
  }

  function startPolling() {
    if (intervalId !== null) return
    intervalId = setInterval(checkVersion, POLL_INTERVAL_MS)
  }

  function stopPolling() {
    if (intervalId === null) return
    clearInterval(intervalId)
    intervalId = null
  }

  function start() {
    checkVersion()
    if (!document.hidden) startPolling()
  }

  function stop() {
    stopPolling()
  }

  return { start, stop }
}
```

- [ ] **Step 7: Implement visibility handling**

In `frontend/src/versionWatch.ts`, add a `visibilitychange` listener inside `start()`, and remove it in `stop()`:

```typescript
  function handleVisibilityChange() {
    if (document.hidden) {
      stopPolling()
    } else {
      checkVersion()
      startPolling()
    }
  }

  function start() {
    checkVersion()
    if (!document.hidden) startPolling()
    document.addEventListener('visibilitychange', handleVisibilityChange)
  }

  function stop() {
    stopPolling()
    document.removeEventListener('visibilitychange', handleVisibilityChange)
  }
```

(`handleVisibilityChange` is declared above `start`/`stop` in the same closure, alongside `startPolling`/`stopPolling`.)

```typescript
  function handleClick(event: MouseEvent) {
    if (!stale) return
    const target = event.target as HTMLElement | null
    if (target?.closest('input, textarea, [contenteditable]')) return
    window.location.reload()
  }

  function start() {
    checkVersion()
    if (!document.hidden) startPolling()
    document.addEventListener('visibilitychange', handleVisibilityChange)
    document.addEventListener('click', handleClick)
  }

  function stop() {
    stopPolling()
    document.removeEventListener('visibilitychange', handleVisibilityChange)
    document.removeEventListener('click', handleClick)
  }
```
